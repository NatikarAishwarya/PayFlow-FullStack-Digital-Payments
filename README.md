# PayFlow — Full-Stack Digital Payments Demo

A PhonePe-inspired educational web application for demonstrating frontend + backend development.

## Included
- Responsive payment dashboard
- Demo user account and balance
- Send-money flow
- Scan & Pay UI
- Bill payments
- Mobile recharge
- Add demo money
- Transaction history
- Wallet-style balance
- UI sections for AutoPay, UPI Circle, gift cards, insurance, investments, cards and travel
- Express backend
- SQLite database
- REST API endpoints
- Local persistence

## Run locally
1. Install Node.js.
2. In this folder run:
   `npm install`
3. Start:
   `npm start`
4. Open:
   `http://localhost:3000`

## Important
This is an educational DEMO. It does not connect to UPI/NPCI, banks, real payment gateways, real QR payments, or real money. Do not enter real UPI PINs, card numbers, CVVs, OTPs or bank credentials.

For production payments, use an authorized payment provider/UPI integration and follow applicable RBI/NPCI/payment-security requirements.

## Current feature reference
The feature scope is inspired by publicly documented PhonePe capabilities such as money transfer, scan & pay, bill payments, recharge, wallet, UPI Lite/Circle/AutoPay, cards, insurance, investments, lending and travel. The project uses its own PayFlow branding and demo data.
