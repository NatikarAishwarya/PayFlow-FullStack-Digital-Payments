# Deployment

## Render
1. Push the project to GitHub.
2. Create a new Web Service on Render.
3. Build command: `npm install`
4. Start command: `npm start`
5. The app listens on the PORT supplied by Render.

## Note
SQLite is suitable for a local educational demo. For production deployment with persistent data, use a managed database such as PostgreSQL and proper authentication/session management.
